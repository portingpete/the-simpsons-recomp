# Original particle module lifetime regression plan

This is a source-qualified design for the next independent fixture, with no
native setup/use/release credit. The separate
[23-span design receipt](../build/restrictive-check-audit/particle-owner-probe-design-v2-20261002.json)
pins the newly examined public resource/parent functions to immutable image
`6df91235...083a0`. It supplements the
[31-span allocation/activation/removal contract](../build/restrictive-check-audit/particle-owner-contract-20261002.json).
No production or test source was changed to prepare it.

A small concrete direct-path input recovered so far is
`bargainbin/bargainbin/challenge_mode/challenge_mode_design.str`, entry6,
`food_swipe_rgb.vfx`, decoded offset1,024,096,560 bytes, SHA256
`a2c6d080424cdb11bea84b31abb7f7114f7f5e90f44ba831e78d5e80468b3232`.
It contains one revision15 `.prt` module. Its count1 requests capacity8;
type0/flags0/mode0 selects the ordinary direct family candidate. Definition
starts at112 and parameters at416; their whole semantic parameter contract
still requires the original consumer. Both archive and decoded named-payload
hashes were independently rechecked before selecting this input.

Its primary original texture GUID contains `shine`, with a zero secondary
GUID. The same archive's entry4 `Challenge_Mode_Design.itxd` contains a
64×64 named texture `shine`, metadata SHA256
`16c7d4a6abb4fdd34aea8ac47eefbf880b1f44c6930c53d182d101fc435970a4`.
There are62 packaged `shine` occurrences, so that name is a dependency
candidate only. The fixture must prove original registry/group lookup selects
the owned dictionary occurrence; publishing a raster pointer manually would
leave the missing lifetime contract unresolved.

Run immutable shared-pool and embedded-owner cases in separate processes.
Select the embedded branch through the original pool budget/availability
producer; do not manufacture its callback flag. Record a rejected malformed
case and a later valid baseline independently so one frontier cannot hide
the remaining cases. Check wrong/truncated relocation spans, invalid ring
cursors, stale texture/module/parent references, retirement ordering and
failure cleanup through the original owner graph.

After that baseline, a private serialized-copy count5,001 case can exercise
the source-produced626 blocks/capacity5,008. It is a synthetic producer-range
case, not a shipped occurrence. It must first prove actual allocation,
activation, use and original removal before changing the native4,096 caps
or their fixed staging allocation. Stock requests stop at256, while the
signed maximum's rounding to32,768 still needs independent validity analysis.

The direct fixture does not qualify the2,434 shipped `.prt` module rows with
types1/4/6. They use `8275FE78` and need their own original use/lifetime cases.
The existing direct shader fixture seeds emitter/ring/bucket fields; it
remains useful for native pixel comparison but does not complete the public
serialized module path above. Allocator/service/bootstrap and cached-owner
shutdown have not yet executed under this design.
