# Original Im2D shader calculations

The two Im2D pixel expressions and the matching unlit vertex branch now have
native HLSL implementations in `renderer/im2d.hlsl`, compiled ahead of time.
They are qualified independently of the guarded game draw. The native packed
vertex decoder now feeds these shaders in GPU tests. Fixed-function resource
ownership/binding, alpha testing, blending, depth and RGB10A2 output still need
integration with the game.

The real original CPU generator8240EAA8 receives the exact two stage0 schedules
from82408CC0. The fixture calls the original queue helpers and state commit,
then executes the original source builder. The flat program returns interpolated
diffuse RGBA. The textured program samples stage0 and multiplies every component
by diffuse. The entire generated program is compared after removing whitespace,
and bounded output writes are checked. No source text or successful result is
substituted for that original CPU execution.

The original vertex key source is the prefix82410A74..82410B94. Its20 options
are generated by original82410588 from the22-word key; two final words carry
the raster width/height. The fixture supplies the reviewed key mapping and
executes the original texture-coordinate/color-use helpers. It is not a test
of the complete82410A68 shader creation function. Both exercised schedules
select screen positions, color0, no lighting and no fog. Texturing additionally
selects passthrough texture-coordinate0. CPU records and native scalar state
are restored/checked; console shader compilation and device calls do not run.

The shipped vertex source at82063228 is21,677 bytes, SHA256
`9fbcd5e2391752e25a6e7ddf22704e0f271fb562747b157b1cc6f5421f55b78b`.
Its selected branch computes X=(x-0.5)*scaleX-1 and
Y=-((y-0.5)*scaleY-1), preserves Z and sets W=1 regardless of input RHW.
Color0 is clamped from above to1 at the vertex, before interpolation. Negative
color values remain negative. UV0 passes through unchanged. Original8240FE00
at82410340..824103B0 supplies scaleX=2/width and scaleY=2/height using fdivs;
the original numerator at821DD0E4 is float2.0. The native expressions preserve
these operations. Native rasterizer/console half-pixel equivalence is still
separate from this verified shader-space transform.

The native GPU fixture observes VS outputs through test-only stream output,
checking exact positions, Z/W, colors and UVs at1280x720,640x720 and17x13.
It also reads actual float render targets for flat/textured quads with varying
colors and RHW. These cases distinguish vertex clamping from pixel clamping,
verify affine interpolation and sample/color multiplication, and retain negative
outputs in floating storage. They are numerical fixtures, not game screenshots.
Both WARP and hardware results are recorded in `build/im2d-upload`.

`renderer/im2d_vertices.cpp` accepts the exact original three-element Im2D
declaration: FLOAT4 at0, D3DCOLOR at16, FLOAT2 at20, stride28. The original
frontend producer826D54B8 loads four input RGBA bytes and builds0xAARRGGBB at
826D5690..826D5708, stored as big-endian A,R,G,B. The native decoder expands
this to RGBA/255, without borrowing caller storage. It preserves every position,
RHW and UV bit while rejecting nonfinite active XYZ or textured UV; flat unused
UV and ignored RHW retain their bits. Opaque declaration stack bytes remain
preserved by the existing declaration owner and do not select semantics.
The normalized D3DCOLOR interpretation is corroborated by Microsoft's
[declaration documentation](https://learn.microsoft.com/en-us/windows/win32/direct3d9/d3ddecltype)
and the read-only reference's
[D3DCOLOR mapping](https://github.com/hedge-dev/UnleashedRecomp/blob/main/UnleashedRecomp/gpu/video.cpp).
The game's own declaration bytes and original quad execution establish the
layout and byte order; no reference engine implementation was copied.

The5,956 decoder checks cover every byte value in each distinct color channel,
unaligned source, signed zero, ignored NaN bits, active nonfinite rejection,
source extent/count limits, incompatible declarations, all opaque byte values,
owned output after source mutation/declaration release and unchanged references.
Normalized color values are computed at compile time. Every channel is also
checked under downward, upward and toward-zero host rounding: the output bits
remain identical and the decoder preserves rounding mode and exception flags.
The3,392 GPU checks on each of WARP/hardware now also include actual flat and
textured float-target pixels produced from original packed source vertices.
This does not establish console filtering, blend, depth or target equivalence.

The driver fixture executes original826D54B8 with32 synthetic caller rectangles,
colors and UV schedules, including the original90-degree rotation branch.
It uses the actual original camera, RenderWare setter and Im2D callback table;
all original vertex construction, color packing, allocation and memcpy remain
AOT. Exact native uploaded bytes match the original stack source and decode to
the expected XY/Z/RHW/RGBA/UV. The fixture reaches the real82408CC0 guard before
draw, restores its synthetic caller/global data and checks unchanged native
targets/state/draw/present counts. It is not a game menu or gameplay test.
Original CPU shader execution now checks both complete20-entry macro lists.
Pinned original functions/source and test inputs are in
`build/im2d-upload/shader-evidence.json` and `shader-original-chain.txt`.

ReAgent's installed Ghidra bridge exported ten selected original functions plus
one inlined helper to `analysis/reagent/im2d-fixed-function-03`:1,834 original
words,76 direct BL sites and64 indirect sites. Every original word and direct
target matched the independent decoder. Generic Ghidra ABI assumptions remain
unverified: several save helpers are still incorrectly inferred to return
parameters in exported C. Those expressions were checked against instructions;
no decompiled replacement was accepted as an implementation.
